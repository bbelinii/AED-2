# Algoritmos de Ordenação — AEDS2

Material focado SOMENTE nos algoritmos estudados:

1. Bubble Sort
2. Selection Sort
3. Insertion Sort
4. Merge Sort
5. Quick Sort
6. Heap Sort

O foco maior está em **Quick Sort** e **Heap Sort**, incluindo várias versões comuns em provas práticas de AEDS2.

Também há uma pasta de **ordenação polimórfica**, usando exatamente esses seis algoritmos com `Comparator<T>` e uma interface `Ordenador<T>`.

## Como estudar

1. Leia `00_guia/01_mapa_mental.md`.
2. Revise um algoritmo por vez pelo README da pasta correspondente.
3. Rode a versão básica.
4. Compare com as variações de prova.
5. Faça os exercícios de `08_provas/` sem olhar o gabarito.

## Estrutura

- `00_guia/` — visão geral, complexidades e como reconhecer cada algoritmo.
- `01_bubble/` — Bubble Sort e variações.
- `02_selection/` — Selection Sort e variações.
- `03_insertion/` — Insertion Sort e variações.
- `04_merge/` — Merge Sort e variações.
- `05_quick/` — Quick Sort com foco aprofundado.
- `06_heap/` — Heap Sort com foco aprofundado.
- `07_polimorfismo/` — os seis algoritmos usando polimorfismo e `Comparator<T>`.
- `08_provas/` — exercícios e simulado prático.
- `09_resumos/` — revisão rápida para prova.
