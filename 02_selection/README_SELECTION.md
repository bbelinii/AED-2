# Selection Sort

## Ideia
Escolhe quem deve ocupar a próxima posição definitiva.

Versão mais comum:
- começa no índice `i`;
- procura o menor de `i` até o fim;
- troca o menor encontrado com `v[i]`.

## Variação importante de prova
Em vez de procurar o menor e mandar ao início, pode procurar o maior e mandar ao final.
